# Internal Release v0.1.9

## LAN Connectivity Support for Roblox Studio Bridge

### Bridge Host Binding
- Added `-host` flag to `roblox-studio-mcp` (default: `127.0.0.1`).
- Setting `-host 0.0.0.0` allows the HTTP bridge to accept connections across the local network.
- Relaxed HTTP Host header validation to permit external LAN host headers when the server is bound to `0.0.0.0`, while keeping browser CSRF protections and pairing token security intact.

### Companion Plugin Configuration
- Added a Bridge URL input field to the Roblox Studio plugin widget.
- Users can now specify the IP and port of the machine running the MCP server (for example `http://192.168.1.50:58741`).
- The configured bridge URL is persisted across Studio sessions in plugin settings.
- The Pair / Connect button dynamically tests and connects to the target address.

### Artifacts and Binaries
- Rebuilt binary `dist/roblox-studio-mcp.exe`.
- Updated embedded companion plugin Luau source (`plugin/src/init.luau`) and synchronized to local Studio installation.
