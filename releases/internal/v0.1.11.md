# Internal Release v0.1.11

## Tool Gaps and Plugin Hardening

### Plugin Reliability
- A tool that throws inside the plugin no longer stops its polling loop. The error comes back as `LUAU_ERROR`.
- Failed calls in Edit are rolled back through `ChangeHistoryService`, so a tool call never leaves a half-applied change.
- Results that cannot be encoded as JSON come back as `COERCION` instead of timing out.

### Server Context and Logs
- The plugin now also runs jobs in the playtest server DataModel. `execute_luau` with `context: "server"` runs there, and fails at once with `WRONG_MODE` when no playtest is running.
- Bridge jobs are routed by DataModel role, and canceled jobs are removed from the queue so they never run late.
- Console log entries are tagged `edit`, `server` or `client` by the DataModel that printed them.

### Tool Results
- Every result is a JSON object. Plain values are wrapped as `{"value": ...}`, which fixes string and number results from `execute_luau`.
- Tables returned from `execute_luau` are serialized recursively.
- Bare arrays for properties are converted using the property's current type (Vector3, Vector2, UDim, UDim2, Color3, CFrame, NumberRange), and BrickColor accepts a color name.
- NumberRange, Rect, BrickColor, ColorSequence and NumberSequence are supported in both directions.

### Tools
- `studio` `selection` returns the selected instances.
- `get_instance_tree` supports `include_properties` (every script-readable property through ReflectionService, or a list of names) and `cursor` pagination with `truncated` and `next_cursor`.
- `find_instances` filters by `attribute` and `attribute_value`, defaults to 500 matches, reports `truncated`, and rejects invalid patterns, class names and attribute names.
- `manage_script` supports `delete` and `run_context`, places new scripts under the parent named in `path`, validates `script_type`, and reports failed source writes.
- `create_physics_joint` supports `AlignPosition` and `AlignOrientation`, maps `lower`/`upper` to `LowerAngle`/`UpperAngle` on hinges, accepts any joint property, and skips attachments for part-based joints.
- `build_tree` and `set_properties` report properties and attributes that could not be set in `failed`.
- `call_method` and `delete_instance` return errors for unknown methods and locked instances.
