# Internal Release v0.1.5

## Pixel-Perfect UI Overhaul, Cosmic Dust & Anomaly Gameplay Loop

### Summary of Deliverables
- Frontend UI Precision Overhaul:
  - Fixed the blurry/embossed tab font bug: set `ApplyStrokeMode = Enum.ApplyStrokeMode.Border` across all UIStroke instances so outlines strictly wrap outer button containers rather than distorting text characters.
  - Eliminated the 300px empty dead void: tightened the Dashboard modal height to a comfortable 395px, snugly framing the cards with balanced margins.
  - Fixed the "ghost" disabled button bug: disabled buttons now render with a distinct `#fdf6e3` (Base3) recessed surface, a visible 1px stroke, and muted `#839496` typography, providing unmistakable visual affordance.
  - Added clean modal occlusion: the background TopBar is hidden while the modal is active, preventing any awkward peaking behind the top border.
  - Enhanced close button: replaced the plain red square with a stylized circular pill button with smooth hover states.
- Second Currency & Transmutation Engine (Cosmic Dust):
  - Added `Cosmic Dust` currency (`◆`) alongside `Starlight` (`★`).
  - Wired the 3D **Cosmic Dust Alembic** station in the Orrery Wing: allows players to condense 100 Starlight into 1 Cosmic Dust.
  - Added Orrery upgrades: *Stellar Cartography* (+25% multiplier to all yields) and *Gravity Dust Loom* (+50/s passive production).
- Celestial Anomaly Random Events:
  - Implemented 60-second random Celestial Anomaly (Shooting Star / Cosmic Flare) spawner in the Atrium and Courtyard.
  - Interacting with an anomaly grants a large instant Starlight bounty and activates a 20-second 2x Frenzy.
  - Added animated golden banner notifying all players when an anomaly manifests.
- Data Persistence (`DataStoreService`):
  - Implemented safe, pcall-wrapped auto-saving every 60 seconds and on player disconnect, preserving Starlight, Cosmic Dust, and upgrade levels across play sessions.
