# Internal Release v0.1.7

## Meteor Shower active gameplay and full UI rebuild

### Gameplay
- New ServerScriptService.MeteorShower module: stars fall around every player with a glowing ground ring.
  - Stand in a gold ring when it lands to catch it. Cyan Comets are rare and worth 6x.
  - Red rings are Void Shards: knockback, slowdown, combo reset.
  - Combo multiplier up to x4, resets after 5 seconds without a catch. Cosmic Dust at every 25 catches.
  - Starfall wave every 55 seconds (14s, double spawn rate).
  - Catch reward is 8x starlightPerClick times combo, so Lenses and Constellations still matter.
- Dash ability (Q or Left Shift, 2.5s cooldown).
- Server is authoritative: catch resolution happens on the server at impact time.

### UI
- Whole HUD and dashboard are now built in code by ObservatoryController with the dark CosmosTheme palette (ReplicatedStorage.CosmosTheme).
- New HUD: resource chips with count-up, combo meter, ability bar, banners, screen toasts, world damage numbers, hit flash and camera shake.
- New dashboard: sidebar tabs, upgrade cards with affordability states, prestige card with progress bar, perk cards, How to Play page.
- New welcome card.

### Structure
- Environment animation moved to StarterGui.ObservatoryHUD.EnvironmentAnimator.
- New remotes: MeteorEvent, StarfallWave (DashUsed reserved, unused).
- Old Solarized UI instances removed. SolarizedTheme module is no longer used.

### Not yet verified
- Not play tested from the MCP bridge. All scripts compile (loadstring check).
