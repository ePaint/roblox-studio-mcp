# Internal Release v0.1.10

## Plugin Installation Path and UI Layout Ordering Fixes

### Plugin File Naming and Target
- Fixed plugin installation target filename from `RobloxStudioMCP.server.luau` to `RobloxStudioMCP.lua`.
- Roblox Studio user local plugin folder (`%LOCALAPPDATA%\Roblox\Plugins`) executes `.lua` plugins. Existing `.server.luau` files were ignored by the engine while stale `.lua` files continued to run.
- Added automatic cleanup of legacy `.server.luau` files during `--install-plugin`.

### UI Component Layout Order & Defaults
- Explicitly set `UIListLayout.SortOrder = Enum.SortOrder.LayoutOrder` to prevent alphabetical property ordering of GUI elements.
- Assigned deterministic `LayoutOrder` to all widgets:
  1. `StatusLabel` (LayoutOrder: 1)
  2. `UrlInput` (LayoutOrder: 2)
  3. `CodeInput` (LayoutOrder: 3)
  4. `PairButton` (LayoutOrder: 4)
- Set `codeInput.Text = ""` and enabled `ClearTextOnFocus = false` so placeholders render cleanly instead of the engine default text "TextBox".
