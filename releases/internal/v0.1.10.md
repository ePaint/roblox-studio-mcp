# Internal Release v0.1.10

## Remote MCP over Streamable HTTP

### Server Transport
- Added `-http` flag to `roblox-studio-mcp` (for example `-http 0.0.0.0:58742`) to serve MCP over streamable HTTP instead of stdio.
- Lets an MCP client on another machine drive Studio while the server runs on the Windows host, so `capture_viewport` and `studio` save keep working.
- The bridge stays on its own `-host` binding (default `127.0.0.1`), so the plugin keeps connecting over localhost.

### Authentication
- HTTP requests require `Authorization: Bearer <token>`.
- The token is generated on first start, saved to `.mcp_http_token` in the working directory, and reused on later starts.
- The endpoint and token are printed to stderr at startup.

### Client Setup
```bash
claude mcp add --transport http roblox-studio http://<windows-ip>:58742/ --header "Authorization: Bearer <token>"
```
